# 方法、数据与记录口径

本文件只说明已经运行的第一阶段实现，不包含后续研究设计。

## 模型与提示

- GPT-5.6 Sol：`reasoning_effort=low/high`。
- DeepSeek-V4-Pro：关闭思考 / 开启思考（high）。
- Qwen3.8-27B：`enable_thinking=false/true`。
- 配对CoT：本项目将PoT作者的FinQA四示例程序改写为文字推导，不另加拒答句。
- 原有拒答CoT：使用VeriFin配套代码的功能性任务模板，无四示例，明确要求证据不足时不猜测。
- PoT：原FinQA四示例，生成Python并交由受限worker执行。

所有确切请求都保存在记录中。`data/prompt_snapshot.json`提供便于审阅的固定提示；它与实际请求核对，而不是从论文标题推测提示。

## 删除比例

`rho=D/N`，N为原可见材料及问题中去重的定量金融/经营事实数，D为删除的事实数。同一指标/实体/期间/单位的重复披露只计一次，年份/页码/单位换算常数不单独计入。固定低/中/高组90/30/30题。已知第2题校勘后，组内实际范围为0.85%-9.09%、15.38%-22.73%、30.77%-66.67%；保留原分组，不按结果重新划组。

## 两种标签政策

数字溯源互斥代理：错误目标作答中，有文档外输入数值则计数值幻觉，否则计关系代理。代理不等于独立证实无依据关系。

独立标签：数值输入来源与关键关系依据分别判断，可同时出现。合法中间结果/换算不因未逐字出现就算编造，纯算术/执行错误不自动算关系幻觉。主比例只计最终采纳推导中的错误目标作答；合法声明条件的回答、明确放弃的错误思路单列。

机器评审隐藏生成模型/提示/档位/删除组元数据，但代码形式可能暴露流程。GPT作为评审者可能共享偏差，公开标签不是人工金标；未知项仍保留在分母。

## 版本与未决项

统一8,192-token原版有8条连接问题和182条截断；仅这些条件重新生成。最终2,517条上限8,192，176条24,576，7条65,536，全部正常结束。适应性预算与重抽样使其不能解释为严格同预算的因果比较。

所有尝试保留，主矩阵只取每条件当前选定的一条输出。校准、历史中间版本、重复机审和网络失败不能追加到2,700分母。150题可答性诊断、16题优先人工检查清单及133题诊断子集均作为敏感性记录，不替代固定完整矩阵。

## E3 N组（已构造，尚未运行模型）

`reproductions/relational-pilot/v2/build_n_control.py`以O/K对应的150道FinQA源题配对构造N。每道N保留其K伙伴删除的所有事实，并保留原FinQA标准程序的数值输入支持；从其余事实中优先移除与目标指标/期间词项重叠较少的事实。目标删除数量按K伙伴匹配。第20和103题没有剩余可删除的非必要量化事实，N等于O；其余148题与K的删除数量一致。

本轮本地检查回放了全部编辑，确认问题、源题配对、修改位置、K/N删除集合互斥及标准程序数值叶子支持。此检查只能验证原标准程序路径仍然可用，不能证明被删事实对所有替代解法或自然语言理解均无关；N的语义无关性仍待人工审核。尚未为N运行API，也没有N条件的模型效果结果。

文件：`data/n_control_150.json.gz`含完整O/K/N配对；`data/n_control_pair_index.csv`列出每题N/K删除数及删除比例；`data/N_CONTROL_README.md`说明两道N=O的特殊情况。构建脚本：`reproductions/relational-pilot/v2/build_n_control.py`。
